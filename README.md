# LED Mapper Configurator — web version

NovaStar LED screen wiring diagrams, port allocation and NovaLCT `.scr` export.
Works offline once opened.

**Open:** https://bunc1112.github.io/led-mapper/

**iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen**. The app then starts full-screen from its icon and works without internet. Exports open the share sheet ("Save to Files", AirDrop, WhatsApp…).

This repository only contains the built web app; it is published automatically from the main project.
